# Conselho MONEY

Plugin privado da Xpansive para instalar o mesmo sistema de decisão em outra conta ou computador.

MONEY funciona como facilitador e recomendador central. Oito especialistas investigam seus próprios domínios, confrontam teses e preservam divergências materiais. O sistema encerra com uma recomendação principal, em vez de devolver opiniões soltas ao usuário; o dono operacional decide. BLACK OS pode adicionar memória depois que autenticação e isolamento forem validados no ambiente de destino.

## O que está incluído

- MONEY como porta de entrada e responsável pela recomendação quando não for parte interessada;
- Eugene Schwartz, Clayton Makepeace, Gary Halbert, John Carlton, Gary Bencivenga, Stefan Georgi, Robert Greene e Quentin Tarantino como reconstruções operacionais documentadas;
- Constituição, quórum mínimo, primeira rodada independente, contraditório e auditor separado;
- fluxo automático de alinhamento e construção;
- contrato final com Big Idea, premissa, mudança de crença, mecanismos, promessa, oferta, prova, público, expressão e próximo movimento;
- perfil pessoal de Lucas e memória do projeto MONEY + BLACK OS em camadas separadas;
- fallback honesto quando subagentes ou BLACK OS não estiverem disponíveis.

Os conselheiros são modelos operacionais baseados em material documental. O plugin não afirma que eles são, incorporam ou possuem a consciência das pessoas reais.

## Instalação

O repositório é privado. Dê à conta de destino acesso ao GitHub e execute:

```powershell
codex plugin marketplace add Xpansive7/conselho-money-private
codex plugin add conselho-money@xpansive-private
```

Reinicie o Codex, abra uma conversa nova e execute `$conselho-money-setup`. Veja [o quickstart](docs/QUICKSTART.md) para o primeiro teste e [os evals](docs/EVALS.md) para validar o comportamento.

## Uso principal

> Use $money-chair. Absorva este briefing, faça somente as perguntas que mudam a decisão e entregue uma direção estratégica completa.

MONEY pode apresentar territórios no começo para calibrar. Depois da deliberação, ele deve escolher uma rota, sustentá-la e declarar o que faria a recomendação mudar.

## Privacidade

Não inclua tokens, credenciais ou memórias de clientes no Git. O perfil pessoal e a memória MONEY + BLACK OS permanecem separados dos cérebros profissionais. Consulte [privacidade e dados](plugins/conselho-money/docs/privacy-and-data.md).
