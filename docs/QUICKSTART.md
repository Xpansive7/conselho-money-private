# Quickstart

## Instalar em outra conta ou computador

O repositório deve permanecer privado. Na conta de destino, dê acesso ao GitHub e execute:

```powershell
codex plugin marketplace add Xpansive7/conselho-money-private
codex plugin add conselho-money@xpansive-private
```

Reinicie o Codex e abra uma conversa nova para carregar as skills. Execute `$conselho-money-setup` antes do primeiro uso.

O marketplace exige o campo `policy.authentication`; ele permanece como `ON_INSTALL` por contrato do catálogo. Este release não inclui MCP, app, credencial nem conexão autenticável, então nenhuma memória remota é ativada pela instalação.

## Primeiro teste

Use:

> Use $money-chair. Quero transformar este briefing em uma direção estratégica completa. Faça apenas as perguntas que podem mudar a decisão, confronte os especialistas necessários e conclua com uma rota principal.

O resultado correto tem duas fases. Primeiro, MONEY recupera o contexto, faz até três perguntas materiais e recomenda um território. Depois, integra os pareceres e entrega Big Idea, premissa, mudança de crença, mecanismos, promessa, oferta, prova, público e contexto de uso, direção de expressão e próximo movimento.

## Falar com um conselheiro

Invoque a skill correspondente, por exemplo:

> Use $conselho-money-john-carlton em modo isolado e critique somente o hook e a cena desta peça.

A resposta isolada não representa o conselho inteiro.

## BLACK OS

O release mantém a conexão remota desativada. O conselho produz um registro manual e não alega que recuperou ou salvou memória. Conecte BLACK OS somente depois de validar autenticação por conta, isolamento por proprietário e namespace, acesso negado, exportação, exclusão e revogação. Nunca coloque tokens no repositório.

## Atualizar

```powershell
codex plugin marketplace upgrade xpansive-private
codex plugin add conselho-money@xpansive-private
```

Abra uma conversa nova após a atualização.
